## `01` — The Concept

> **Most portfolios blend in. This one stands out.**

DevFolio isn't a portfolio — it's a *statement*. Built for developers who want their work to speak before they even say a word. Dark, fast, precise, and entirely yours to own.

No React. No Next.js. No bloat. Just clean HTML, CSS, and JavaScript — the way the web was meant to be built.

## `04` — Get Started

Three steps. That's it.

<br>

**① Clone**
```bash
git clone https://github.com/omarmetman/devfolio-template.git
cd devfolio-template
```

<br>

**② Make it yours** — open `script.js` and edit:
```javascript
const CONFIG = {
  name: "Your Name",                              // 👈 Your name
  titles: [
    "Full Stack Developer",                       // 👈 Your roles
    "Open Source Contributor",
    "Problem Solver",
  ],
  typingSpeed: 80,
  deletingSpeed: 40,
  pauseAfterWord: 2000,
};
```

<br>

**③ Add Telegram notifications** *(optional but magical)*
```javascript
// Get your bot token from @BotFather on Telegram
const BOT_TOKEN = "YOUR_BOT_TOKEN_HERE";
const CHAT_ID   = "YOUR_CHAT_ID_HERE";
```
> 💡 Every contact form submission lands in your DMs instantly. No server needed.

<br>

## `05` — Deploy in 60 Seconds

```
GitHub Repo  →  Vercel Import  →  Deploy  →  🌐 Live
      ↑                                           ↑
   Your Code                              Your Portfolio
```

1. Push your changes to GitHub
2. Go to [vercel.com](https://vercel.com) → **Add New Project**
3. Import your repo and hit **Deploy**

Done. Your portfolio is live.
