## ⚙️ <span id="-quick-start">Quick Start</span>

Transform this template into your own personal website in just 3 steps.

> **Step 1: Clone the environment**
```bash
git clone https://github.com/omarmetman/devfolio-template.git
cd devfolio-template
```

> **Step 2: Inject your identity**
Open `script.js` and modify the global `CONFIG` object:
```javascript
const CONFIG = {
  name: "Your Name",
  titles: ["Full Stack Developer", "Designer", "Creator"],
  typingSpeed: 80,
  deletingSpeed: 40,
  pauseAfterWord: 2000,
};
```

> **Step 3: Setup Telegram (Optional)**
Want messages sent to your phone? Update `script.js` with your bot credentials:
```javascript
const BOT_TOKEN = "YOUR_BOT_TOKEN_HERE";
const CHAT_ID = "YOUR_CHAT_ID_HERE";
```
